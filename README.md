# app-idiomas
Um app de flashcards no estilo Anki, para adquirir vocabulário de idiomas, começando pelo inglês e construído como se o aluno partisse do zero. O diferencial é o card por sentido: definição em inglês e frase com lacuna, em vez de tradução solta. A meta da jornada é o B2, com cerca de 4.000 famílias de palavras.
